# 🛠️ Руководство разработчика для Select-to-Copy

## 📂 Структура проекта

```
Select-to-Copy/
├── app/                  # Основной пакет приложения
│   ├── __init__.py
│   └── version.py        # Логика версионирования
├── Build_Tools/          # Инструменты для сборки исполняемого файла
│   ├── Select-to-Copy.spec  # Spec-файл для PyInstaller
│   ├── post_build.py     # Скрипт автоматизации после сборки
│   └── ...
├── Select-to-Copy.pyw    # Точка входа (скрипт запуска)
├── VERSION               # Источник правды для версии в режиме разработки
├── logo.ico              # Иконка приложения
├── 00_CrRel_setup.py     # Создание установщика через Inno Setup
├── 00_Move.py            # Обновление портативной версии
└── ...
```

## 📏 Правила и стандарты

### 1. Язык
- **Все комментарии в коде, документация и артефакты должны быть на русском языке.**
- **Имена переменных и логика кода остаются на английском.**

### 2. Версионирование
- **Источник правды:** Файл `VERSION` в корневой директории.
- **Скомпилированные сборки:** Файл `app/version.py` содержит константу `FROZEN_VERSION`, которую НЕОБХОДИМО обновлять перед релизом.
- **Процесс:**
    1. Обновить `VERSION`.
    2. Обновить `FROZEN_VERSION` в `app/version.py`.
    3. Запустить сборку.

### 3. Процесс сборки
- Используйте `Build_Tools/SpecCompiler.pyw` для сборки приложения.
- Скрипт `post_build.py` автоматически выполнит копирование файлов и очистку.
- Собранный `.exe` после `post_build.py` автоматически не запускается.
- Финальная папка содержит `VERSION`, `LICENSE` и `RUNTIME_MANIFEST.json`.

### 4. Процесс релиза
- Запустите `00_CrRel_setup.py` через проектный Python для создания установщика
  `<AppName>_v<version>_Setup.exe` на настоящем системном рабочем столе.
- Установщик использует Inno Setup 6, предлагает каталог `D:\Apps\Select-to-Copy`
  с fallback на другой fixed drive и содержит отмеченную по умолчанию галочку
  запуска приложения после установки.
- Запустите `00_Move.py` через проектный Python для обновления
  `D:\Portable_soft\Select-to-Copy`.
- При обновлении portable-папки существующий `settings.json` сохраняется.
- Release-скрипты не запускают приложение, установщик или portable-копию.
- Portable-архив не создается штатным полным процессом.

## 🚀 Начало работы

1.  **Установка зависимостей:**
    ```powershell
    .\.venv\Scripts\python.exe -m pip install -r requirements.txt
    ```

2.  **Запуск из исходного кода:**
    ```powershell
    .\.venv\Scripts\pythonw.exe .\Select-to-Copy.pyw
    ```

## Совместимость с клавиатурными перехватчиками

Fallback-копирование отправляет `Ctrl+C` через WinAPI `SendInput` со сканкодами.
Все четыре события помечаются в `dwExtraInfo` значением AutoHotkey `KEY_IGNORE`
(`0xFFC3D44F`). Поэтому LangBarXX и другие AutoHotkey-перехватчики не принимают
служебный левый Ctrl за короткое пользовательское нажатие и не переключают раскладку.
